# Pull Request 規約

## タイトル

- 英語で記述する

## 本文

- 日本語で書き、以下のセクションを含める:
  - `## Issues`
    - 関連 Issue は `refs #<番号>`、解決する Issue は `closes #<番号>` と記載する（`closes` は PR の main マージ時に Issue が自動クローズされる）
  - `## Why`
  - `## Summary`
  - `## Changes`
  - `## Verification`
- セクション内の項目はハイフンリスト（`- ` プレフィックス）で記述する

## フィードバック対応

- PR のフィードバックに対応したら、必ず当該コメントに返信する。インラインコメントでない場合は `Re: ` を付けて全体コメントで返信する
